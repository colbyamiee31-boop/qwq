# PhysBench-GH EXP0.6 — Latent-State Initialization Robustness (Frozen Protocol)

## Status and purpose

This protocol is frozen **before any EXP0.6 scientific result is inspected**.

EXP0.5/EXP1 matched only the common observable greenhouse state and external forcing across GreenLight-Gym2 (M1) and CSGtom (M2), while all non-common internal states remained model-native. EXP0.6 directly tests whether the previously reported finite-horizon CO2 boundaries, mechanism labels, and decision disagreement can be explained by this latent-state initialization choice.

The experiment is intentionally allowed to overturn earlier interpretations. Retaining the previous 438.537 ppm versus 358.279 ppm separation, the previous mechanism labels, or the EXP3 disagreement events is **not** a pass/fail criterion.

## Scientific question

For fixed common observables and fixed intervention forcing:

1. How much do model-internal intervention responses vary when the **native hidden state** is changed through physically generated prehistories?
2. Is the cross-model CO2 boundary separation larger than, comparable to, or smaller than the within-model latent-state spread?
3. Are native mechanism labels stable to latent-state history?
4. Does the locked EXP3 reference decision disagreement persist when the 61 events are rerun from multiple model-native latent states?

The experiment does **not** claim that the two models possess a shared hidden-state coordinate system.

# 1. Latent states are generated by model dynamics, not by random state perturbation

A latent-state member is created by:

1. starting from the frozen model's native reset/initial parameter state;
2. running the unmodified model through a deterministic **common prehistory forcing**;
3. using the same neutral prehistory natural-ventilation command `uVent/u_vent = 0.3`;
4. leaving all non-common states at the values produced by that model's own dynamics;
5. at the intervention origin, overwriting only the common observable variables required by the benchmark.

No wall, soil, crop, carbohydrate, screen, cover, pipe, or other hidden state is directly perturbed by hand.

For M1 the overwritten common states are:
- main-air temperature;
- main-air vapour pressure;
- main-air CO2;
- canopy temperature.

For M2 they are:
- `T_air`;
- `VP`;
- `CO2`;
- `T_can`.

All remaining native states are retained exactly from the prehistory rollout.

The complete pre-projection common state, post-projection common state, full native-state hash, and projection correction vector must be stored for every run.

# 2. Common deterministic prehistory forcing

## 2.1 Time base

Primary prehistory duration: **72 h**.

Secondary slow-memory duration: **168 h (7 d)**.

Common forcing resolution: **900 s**.

The diurnal clock ends at the benchmark/event intervention clock. For the anchor experiment the intervention origin is local 08:00. For the 61-event decision screen the prehistory is phase-aligned to each event's frozen `hour_decimal` and calendar/day fields already used by EXP3.

M1 retains its native integrator. M2 retains its native 30-s Euler step; the common 900-s forcing is piecewise constant within each interval.

## 2.2 Base diurnal prehistory

For local clock hour `h`:

- global radiation:
  `I_base = 600 * max(0, sin(pi*(h-6)/12)) W m-2` for 06:00–18:00, else 0;
- outdoor temperature:
  `T_base = 20 + 4*sin(2*pi*(h-8)/24) degC`;
- outdoor RH:
  `RH_base = 70 - 10*sin(2*pi*(h-8)/24) %`;
- outdoor CO2:
  `CO2_base = 415 ppm`;
- wind speed:
  `1.5 m s-1`;
- sky temperature:
  `T_sky = T_out - 6 degC`;
- soil-boundary temperature:
  `19 degC`.

Outdoor vapour pressure is recomputed from the benchmark saturation-vapour-pressure convention.

## 2.3 Four prehistory factors

The latent-history ensemble varies four common forcing factors:

A. thermal preload:
- low = -3 degC applied to outdoor temperature;
- high = +3 degC;
- soil-boundary temperature receives half of the thermal offset;
- sky temperature remains `T_out - 6 degC`.

B. humidity preload:
- low = -10 RH percentage points;
- high = +10 percentage points;
- RH is hard-clipped to [35, 95]%.

C. radiation preload:
- low = 0.70 x `I_base`;
- high = 1.30 x `I_base`.

D. outdoor CO2 preload:
- low = -25 ppm;
- high = +25 ppm.

The centre history H00 uses zero thermal/RH/CO2 offsets and radiation multiplier 1.0.

These factor values are fixed before viewing any response result.

# 3. Prehistory ensembles

## 3.1 Primary anchor ensemble — 17 history-derived states

The 72-h primary anchor ensemble contains:

- H00: centre history;
- H01–H16: the complete 2^4 corner factorial across factors A–D.

All 17 history-derived states are retained. No history may be dropped because it moves a result in an inconvenient direction.

The original native-reset initialization from EXP0.5 is also rerun as **HNR**, but HNR is a reconstruction/reference condition and is not counted as one of the 17 history-derived members.

## 3.2 Resolution-IV subset for expensive secondary propagation

For mechanism robustness and the full 61-event decision screen, use H00 plus the following eight corner histories satisfying the frozen half-fraction relation:

`D = A * B * C`

with A/B/C coded as -1 or +1.

This yields eight balanced, main-effect-orthogonal corner histories plus the centre history: **9 history-derived members**.

HNR is again retained separately as a reconstruction condition.

## 3.3 Slow-memory extension

At the anchor state only, repeat H00 + the eight resolution-IV histories using **168 h** prehistory.

The 7-d extension is secondary and tests whether the 72-h result is dominated by slower crop/structural memory. It is not used to redefine the primary 72-h ensemble.

# 5. Primary anchor endpoints

## 5.1 H900 CO2 response boundary

For every H00–H16 latent state and for HNR:

`Delta_CO2(C0) = CO2_HIGH(900; C0) - CO2_LOW(900; C0)`

with LOW native ventilation command = 0.1 and HIGH = 0.9.

Use exactly the inherited EXP1.4 search rules:

1. fixed scan 250–600 ppm in 25-ppm increments;
2. detect every sign-changing bracket and exact grid zero;
3. bisection until bracket width <= 1e-4 ppm or absolute response <= 1e-7 ppm;
4. hard cap 50 iterations;
5. deduplicate roots within 1e-3 ppm;
6. do not assume uniqueness.

Report root count and every root. A primary boundary is populated only for a unique root.

## 5.2 Within-model latent spread versus between-model separation

For history-derived members with unique roots in both models, report without imposing a favourable threshold:

- M1 unique-root range, median, IQR;
- M2 unique-root range, median, IQR;
- within-model latent span for each model;
- matched-history absolute M1–M2 root gap;
- median and range of matched-history root gaps;
- root-envelope overlap length;
- ordered separation margin if the two envelopes do not overlap;
- ratio of median matched-history gap to each within-model latent span.

If root topology differs or roots disappear, that topology change is itself a result and must not be converted into an artificial numeric root.

## 5.3 Matched HIGH-minus-LOW responses

At indoor CO2 = 500 ppm, compute HIGH-minus-LOW response for:

- air temperature;
- absolute humidity;
- CO2;

at 15 min and 30 min for all 17 history-derived members.

Report sign stability and magnitude distribution by model.

# 7. Full 61-event decision latent-state screen

For each locked event, run:

- HNR reference;
- H00 centre;
- eight resolution-IV 72-h latent histories.

For every history and model, generate the same five-action response grid:

`{0.1, 0.3, 0.5, 0.7, 0.9}`

at 15 and 30 min.

Then apply the **unchanged locked EXP3.1 reference decision definition**:

- equal T/AH utility weights;
- observational-gradient scaling inherited from EXP3.1;
- quadratic command-coordinate cost;
- primary lambda domain [0,1];
- exact lambda partitioning and lower-action tie break.

This choice is deliberate: EXP0.6 isolates latent-state initialization. It does not attempt to solve action-dose comparability or utility-scale uncertainty in the same experiment.

Primary 15-min decision outputs over the 9 history-derived members:

- disagreement-event set for each latent history;
- per-event disagreement persistence out of 9;
- mean integrated disagreement per history;
- Jaccard similarity of each history's disagreement set with the HNR reference set;
- persistence of HNR events 27/86/89, reported as pre-locked events but **not required to persist**;
- number and identity of new latent-sensitive disagreement events;
- direction of model-swap regret as a descriptive secondary endpoint.

No event is dropped based on latent-history behaviour.

Scientific movement is not a CI failure.

CI/runtime fails only if:

1. frozen source commits do not match;
2. inherited benchmark/input hashes do not match;
3. any required state or response becomes non-finite;

5. a prehistory cannot be replayed deterministically;

# 10. Interpretation rules frozen in advance

Possible outcomes and their interpretation:

### A. Small within-model latent spread, large persistent cross-model gap
Supports the statement that the reported cross-model response difference is not an artifact of one native-reset hidden-state choice.

### B. Within-model latent spread comparable to cross-model gap
Requires attribution to both model formulation and latent-state uncertainty; the original single-initialization cross-model contrast is insufficient by itself.

### C. Strong envelope overlap or topology instability
The finite-horizon boundary is strongly latent-state conditioned and cannot be presented as a stable cross-model separator.

### D. Decision disagreement stable across latent histories
Supports robustness of the locked decision-sensitive cases to native hidden-state initialization, while leaving action-dose and utility-scaling questions unresolved.

### E. Decision disagreement disappears or changes substantially
Shows that earlier decision consequence was materially initialization-dependent.

No outcome is labelled a failed scientific experiment.

# 11. Explicit exclusions

EXP0.6 does not:

- match M1 and M2 hidden-state coordinates;
- calibrate either model;
- introduce physical airflow-dose matching;
- change EXP3 utility scaling;
- lower the realised-actuator E5 evidence standard;
- rank M1 and M2 by empirical correctness;
- use result-dependent history selection;
- assume that GreenLight and CSGtom represent the same greenhouse structure.

Those questions are handled by separate planned experiments.
