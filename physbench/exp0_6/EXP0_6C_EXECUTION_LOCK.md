# PhysBench-GH EXP0.6C — 61-Event Decision Latent-State Robustness Execution Lock

Frozen before EXP0.6C latent-history decision outcomes are inspected.

## Scientific target

EXP0.6C executes Section 7 of the already-frozen EXP0.6 protocol. It tests whether the locked EXP3.1
61-event decision disagreement is robust to model-native hidden states generated by deterministic event-aligned
72-h prehistories.

This experiment isolates **latent-state initialization only**. It does not solve physical ventilation-dose
equivalence or utility-scale robustness.

## Event-aligned prehistory

For every event × history-derived member × model:

1. start from the frozen model-native reset/initial state;
2. generate the same deterministic EXP0.6 72-h prehistory forcing;
3. end the prehistory at that event's frozen `hour_decimal`;
4. align the model calendar using the same calendar/day representation already inherited by EXP3.1;
5. use neutral natural ventilation command 0.3 throughout the prehistory;
6. do not manually perturb hidden states.

At the decision origin overwrite only:
- indoor air temperature = event `event_Tair`;
- indoor vapour pressure = event `in_vp_pa`;
- indoor CO2 = event `CO2_pre_ppm`;
- canopy temperature = event air temperature.

Every other native state is retained from the prehistory.

For HNR, reproduce the original EXP3.1 native-reset initialization exactly; no generated prehistory is used.

No post-event observations are used for action selection.

## Decision definition

Use the locked EXP3.1 decision rule without modification:
- equal T/AH utility weights;
- observational-gradient scaling from frozen D2 gradients;
- reference action 0.1;
- quadratic command-coordinate cost;
- exact lower-action tie break;
- primary lambda domain [0,1];
- secondary lambda domain [0,3];
- exact analytic lambda partition.

## Primary EXP0.6C outputs

At 15 min and lambda in [0,1], report for each of the nine history-derived members:

- disagreement-event set;
- number and fraction of events with any disagreement;
- mean and median integrated disagreement measure;
- mean integrated normalized action gap;
- mean symmetric cross-model regret;
- mean symmetric predicted outcome divergence;
- Jaccard similarity of the disagreement set to HNR.

Across the nine histories report:

- per-event disagreement persistence count out of 9;
- persistence fraction out of 9;
- histories in which each event disagrees;
- persistence of pre-locked HNR events 27, 86, 89;
- new latent-sensitive disagreement events not in {27,86,89};
- events disappearing relative to HNR;
- union and intersection of history-derived disagreement sets.

Directional model-swap regret is descriptive:
- M1-selected action evaluated by M2;
- M2-selected action evaluated by M1;
- signed asymmetry = first minus second.

No persistence threshold is used to declare scientific success.

## Reconstruction hard gate

HNR must reproduce locked EXP3.1 at 15 min, lambda [0,1]:

- disagreement event IDs = [27, 86, 89];
- mean integrated disagreement = 0.024552427907011506;
- mean normalized action gap = 0.006138106976752877;
- mean symmetric cross-model regret = 0.001645164794050128;
- mean symmetric predicted outcome divergence = 0.01691271675501554.

Numeric reconstruction tolerance for these means: 1e-10.

## Runtime hard gates

Fail closed if:
- the input SHA or event count differs;
- the history subset differs;
- any required prehistory/action state is non-finite;
- requested/applied ventilation differs;
- projected common event state differs by >1e-8;
- a same-run saved latent state cannot be restored exactly;
- action-grid rows are incomplete or duplicated;
- M1/M2 event/action/history schemas differ;
- exact lambda partitions fail to cover the declared domain;
- HNR reconstruction fails.

Scientific changes in disagreement sets, persistence, regret, or outcome divergence are **not** runtime failures.

## Interpretation boundary

Allowed:
- decision disagreement is stable or unstable to latent-state initialization;
- particular events are persistent, lost, or newly latent-sensitive;
- model-swap regret direction varies or persists across latent histories.

Not allowed:
- either model is the empirically correct controller;
- a native command fraction is equal physical airflow across models;
- real-world optimal ventilation has been identified;
- the 61 observational events validate realized actuator performance.
